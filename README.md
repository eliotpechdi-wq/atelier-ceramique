# Simulateur d'atelier céramique

Simulateur réglable des coûts matériels et du rendement d'un atelier de céramique : dimensions des pièces, terre, émaux, four, équipement et cours.

Page en ligne : https://eliotpechdi-wq.github.io/atelier-ceramique/

Tout tient dans `index.html` (HTML, CSS et JavaScript sans dépendance). Les réglages sont enregistrés dans le navigateur de chaque visiteur.

Prix TTC indicatifs (France, novembre 2026), hors salaires. À confirmer par devis.
